# Skypro wallet
## Сделан на курсе Skypro. Это веб-сайт для отслеживания расходов и их аналитики. 

## Реализован функционал создания, удаления, редактирования расходов, выбор дат за конкретный период и их визуализация на диаграмме, авторазация.

## Использованные технологии: Vue, css, scss, html, js.

## Установка
### Для установки проекта необходимо выполнить следующие шаги:

### 1.  **Клонировать репозиторий:**
    bash
    git clone github.com/AntonZakharo/skypro-wallet
    cd skypro-wallet
    

### 2.  **Установить зависимости:**
    powershell
    npm install
    
### 3. **Запуск**
    powershell
    npm run preview
